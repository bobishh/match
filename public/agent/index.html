Open Match locally

  1. Install dependencies in match/ with npm install.
  2. Build the browser sync runtime with npm run build:iroh.
  3. Start the app with npm run dev.
  4. Open http://127.0.0.1:5173/. Agent documentation is at http://127.0.0.1:5173/agent/.

For a production static build, run npm run build and serve dist/. Workspaces are stored in the browser's IndexedDB.

Workspaces and Presets

Match supports multiple independent workspaces. Workspaces can be created from presets (such as the default Job search board) or initialized as a Blank board with customizable columns (To do, Doing, Done) and custom field schemas.

Generic WebMCP tools & Legacy Aliases

When Match is open in an environment exposing WebMCP through document.modelContext or navigator.modelContext, it registers both generic task tools and backward-compatible lead aliases:

list_workspaces

List all local workspaces.

create_workspace

Create a new workspace with preset or blank columns.

list_tasks

Query tasks with optional column and search filters.

create_task

Create a task in a workspace column with custom fields.

move_task

Move a task by ID, target column, or parent task ID.

list_leads

Legacy alias: query job search cards by status.

create_lead

Legacy alias: create lead card with company and role.

move_lead

Legacy alias: move card across job search columns.

list_templates

Read global CV and cover-letter Markdown bases.

get_generation_context

Read lead and template context for local artifact generation.

record_pdf_artifact

Attach generated local PDF artifact to a lead card.

add_document

Attach a note or file reference to a card.

export_workspace

Export workspace as a .match bundle.

Do not send unknown fields or nested raw CRDT payloads. Unknown fields are rejected without mutation.

Two Scoped Connection Flows

  • Sync all (Add my device): Generates an enrollment invitation with a short mutual authentication code. Upon host approval, delegates a signed device certificate and shares your personal catalog across your own devices.
  • Sync workspace (Invite someone): Issues an owner-signed editor grant strictly scoped to one chosen workspace. Guests never receive or learn about unrelated workspaces or your personal root.

Export Guarantees & Browser Lifetime

Exported .match bundles contain public cryptographic proofs (proofs.json), task JSON, and Automerge CRDT history. Private signing keys, personal root documents, and pairing secrets are strictly excluded. Live sync operates while tabs remain open; enrolled trust persists across browser reloads without requiring another QR scan. Remote revocation and central password recovery are explicitly unsupported.
